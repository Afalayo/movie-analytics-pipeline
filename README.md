# movie-analytics-pipeline

ETL pipeline using Python, TMDb API, SQL, and data analysis

## Description
A data engineering project that extracts movie data from TMDb API, cleans data using Python/Pandas, stores data in SQLite, and creates analytics reports.

## Tools
- Python
- Pandas
- SQL
- SQLite
- Matplotlib
- TMDb API

## Pipeline

API → Extract → Transform → Load → SQL Analysis → Visualization

## Reports
- Top rated movies
- Most popular movies
- Yearly movie trends
